📋 자주 하는 작업

  1. 관리 > 학생 일괄 등록에서 새 학기 또는 새 부서 학생을 엑셀로 등록합니다.
  2. 관리 > 사용자 관리에서 담당 부서의 일반 교사·학생 계정, 가입 신청과 부서 이동 요청을 확인합니다.
  3. 달란트 > 달란트 관리 상세 화면에서 잘못 지급된 달란트를 반환합니다.
  4. 상품 > 구매 통계에서 부서별 주문 흐름과 지연 상태를 확인합니다.
  5. 운영 > 보고서, 운영 > 버전, 운영 > 서비스 통계에서 최근 변경 사항과 무료 할당량 사용률을 확인합니다.

💰 달란트 반환과 예외 이력 확인 (v3.60.0)

상세 팝업 요약 4칸

달란트 > 달란트 관리 > 상세 팝업 상단에는 다음 네 가지가 구분되어 표시됩니다.

  • 누적적립 — 지금까지 받은 달란트 합계
  • 총사용 — 실제 상품 구매 확정으로 차감된 달란트만 집계
  • 총반환 — 반환 처리된 달란트 (사용과 별도 집계)
  • 잔여 — 현재 사용 가능한 달란트

반환 처리 방법

  1. 상세 팝업에서 반환할 적립 내역을 찾습니다. 내역 유형은 적립, 예외, 사용, 반환으로 구분되며, 이력은 공통 페이징과 페이지당 항목 수 설정을 사용합니다.
  2. 반환 버튼을 누르고 사유를 입력한 뒤 확정합니다.
  3. 반환되면 해당 건은 총반환에 합산되고, 총사용에는 포함되지 않습니다.
  4. 같은 거래 ID 기준으로 1회만 반환할 수 있으며, 지급 모달의 취소 상태와 동기화됩니다.
  5. 달란트 > 예외 지급/반환 관리에서 예외 지급과 반환 이력을 별도 표로 확인합니다.

24시간 유휴 자동 로그아웃

로그인 후 24시간 동안 사이트를 사용하지 않으면 세션이 만료되어 자동 로그아웃됩니다. 페이지 조회, 클릭, 스크롤, 키 입력 등 활동이 있으면 24시간 타이머가 처음부터 다시 시작됩니다. 새 버전 배포 후 구버전 세션이 감지되어도 재로그인 안내가 표시될 수 있습니다.

🧭 권한 범위 이해

  • 부장 교사는 전체 현황을 볼 수 있지만, 사용자/관리자 수정은 담당 관리 부서와 권한 순위 조건을 따릅니다.
  • 구매 담당 교사가 아닌 부장 교사는 구매 처리에서 담당 관리 부서 범위가 적용될 수 있습니다.
  • 달란트 항목 관리의 퀵 버튼 설정은 가능하지만, 항목 CRUD와 QR 관리는 전도사님 이상 권한 기준을 따릅니다.
  • 로그/작업 이력 화면 직접 조회와 페이지 접근/기능 설정 변경은 관리자 권한입니다.
  • 서비스 통계는 부장 교사 이상이 조회할 수 있으며 GitHub/Supabase/Kakao/Slack 사용량을 매시간 정각 기준으로 갱신합니다. 70%·85%·95% 도달 알림은 운영 Slack 채널로 전송됩니다. 180일 초과 수동 정리 버튼은 관리자(100+)에게만 표시됩니다.
  • 권한명, 구매 상태, 상품 카테고리, 로그/작업 유형은 공통 코드 기준으로 표시됩니다. 로그 상세는 영어 key로 저장하고 화면과 Slack 알림에서는 한글로 변환합니다. 상품 카테고리는 상품 카테고리 관리 페이지에서 관리하며, 그리드에는 내부 코드가 보이지 않고 로우 클릭으로 수정합니다. 상품 이미지는 구매 카드 썸네일과 상세 설명 이미지로 나누어 관리합니다. 명칭 변경은 개별 화면이 아니라 코드 마스터 기준을 확인합니다.

🗳️ 추천 상품 비밀 투표

부장 교사는 상품 > 상품 추천 투표에서 추천 상품의 입력 정보와 상세 이미지를 보고 찬성 또는 반대를 선택합니다. 진행 중 득표 수는 profiles.is_super_admin=true인 최고관리자만 확인하며, 종료된 투표는 변경할 수 없습니다. 구매 URL은 상세 창의 상품 보기 버튼으로 열 수 있습니다.

투표 기준은 추천 등록 시점의 60등급 이상 정원입니다. 본인 투표 전에는 결과가 숨겨지며, 채택 시 추천 등록자에게 상품 추천 채택 1달란트가 자동 지급됩니다. 등록과 종료 결과는 운영관리 Slack 채널에 상품명·익명 득표 수만 안내되고 추천자·투표자 이름은 포함하지 않습니다. 현재 유효 정원이 기존 과반보다 감소한 경우의 종료 처리는 최고관리자 전용입니다.
