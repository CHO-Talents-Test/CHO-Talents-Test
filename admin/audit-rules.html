📝 작업 이력 작성 룰

작업 이력(Audit Trail)에 기록되는 기준과 카테고리를 설명합니다. v4.2.9 기준 작업 이력은 activity_logs의 영어 action/details를 코드북과 공통 매핑으로 한글 치환해 표시하며, details에는 처리 상세만 저장합니다. 상품 카테고리 관리, 이미지 연결, 공지 관리, 달란트 예외 지급 요청/승인, 180일 초과 데이터 수동 정리도 관리 작업으로 기록합니다.

📌 작업 이력 vs 로그의 차이

로그 (admin/logs.html): 모든 시스템 이벤트 기록 (PAGE_VIEW 제외, JS 에러 포함) — 레벨별 필터링
작업 이력 (admin/audit.html): 관리 작업만 필터링한 감사 기록 — 카테고리별 필터링
두 기능은 동일한 activity_logs 테이블을 사용합니다. 작업 이력은 기본 AUDIT_ACTIONS와 activity_logs.action 코드 마스터에 등록된 관리 액션을 표시합니다.
DB 권한 확인: 작업 이력이 비어 있고 로그도 쌓이지 않으면 docs/TASK-047_activity_logs_grants.sql을 적용해 activity_logs INSERT 권한과 RLS 정책을 복구합니다.
사용자 통계와의 구분: 성공 로그인 이력은 user_login_history에 별도 저장되며, 통계 조회 자체는 관리 작업 이력 대상이 아닙니다. admin/audit.html은 표의 행 또는 상세 버튼을 클릭해 기존 상세 모달을 열 수 있습니다.

기준설명
AUDIT_ACTIONS/코드 마스터 등록admin/audit.html의 기본 AUDIT_ACTIONS 또는 DB activity_logs.action 코드 그룹에 키가 등록된 액션이 작업 이력에 표시됩니다
관리 작업 중심사용자/부서/달란트/상품/주문 등의 CRUD 작업이 주 대상

실패/거부도 일부 포함로그인 실패 등 보안 관련은 작업 이력에도 포함될 수 있음

📝 참고 사항

새 작업 이력 추가 방법: 기존 logInfo()로 기록하되, admin/audit.html의 기본 AUDIT_ACTIONS 또는 DB activity_logs.action 코드 마스터에 해당 액션 키와 라벨/카테고리를 등록하면 작업 이력에 표시됩니다.
한글 상세 기준: 신규 로그는 writeLog()에서 영어 key 기반 details만 저장하고, 작업 이력 화면에서 한글로 치환합니다. 기존 로그의 한글 별칭/중복/client details는 docs/TASK-074_activity_logs_english_details.sql로 정리할 수 있습니다.
작업 이력 조회: 운영 > 작업 이력에서 카테고리별, 날짜별, 텍스트 검색으로 조회 가능
보고서/로그 그리드: 보고서 관리와 로그 화면의 페이지당 항목 수 콤보 박스는 각 필터 영역의 우측 하단 위치로 정리되어 동일한 공통 페이징 규칙을 따릅니다.
달란트 상세 이력: 달란트 관리 상세 모달의 이력도 같은 공통 페이징 규칙과 페이지당 항목 수 설정을 사용합니다.
공지 사항: 소개 > 공지 사항에서 전도사님 이상이 등록, 수정, 활성 토글, 열람 현황 조회를 수행하면 권한·설정 카테고리 작업 이력으로 표시됩니다. 열람 현황 화면은 등록일시·등록자와 사용자 유형, 확인/미확인 필터를 함께 보여줍니다.
로그 조회: 운영 > 로그에서 전체 시스템 로그 레벨별 조회 가능. 세션 만료/권한 불일치/페이지 접근 차단 원인은 AUTH_SESSION_MISSING, AUTH_PROFILE_LOAD_FAIL, AUTH_REDIRECT, AUTH_PAGE_ACCESS_CHECK_FAIL 액션으로 확인합니다.
상품 관리 검증: 상품 등록은 상품명·대상·카테고리·썸네일 이미지·구매 URL을 모두 입력해야 저장됩니다. 교사용/학생용 목록의 전체·활성·비활성 필터는 조회 상태일 뿐 별도 작업 이력을 만들지 않으며, 실제 등록·수정·상태 변경만 상품/주문 카테고리 이력으로 남습니다.
180일 수동 정리: 서비스 통계의 180일 초과 정리와 로그의 180일 초과 실제 삭제는 관리자(100+) 전용이며, 성공/실패 액션은 코드 마스터 activity_logs.action 기준으로 작업 이력에 표시됩니다.
Slack 알림 룰: 운영 > Slack 알림 룰에서 WARN+ 로그와 구매/가입/Q&A/서비스 할당량 알림 라우팅을 확인 가능
상품 추천 비밀 투표: 추천 등록·채택·불채택·최고관리자 종료·최고관리자 예외 결정과 채택 달란트 자동 지급만 상품/주문 카테고리 작업 이력으로 확인합니다. 진행 중 집계 열람·직접 결정·정원 감소 종료는 profiles.is_super_admin=true 계정만 가능합니다. 등록·종료 시 운영관리 Slack에도 상품명·결과·익명 득표 수만 안내합니다. 자동 지급 로그와 Slack 모두에서 투표자 이름, 찬성/반대 선택, 추천자 이름은 표시하지 않습니다.
