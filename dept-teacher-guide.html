✅ 일반 교사가 없는 부서에서 해야 할 일

  1. 달란트 > 달란트 관리에서 담당 부서 학생 목록이 정상 표시되는지 확인합니다.
  2. 출석, 성경 읽기, 말씀 암송 등 실제 활동 항목을 선택해 학생에게 달란트를 지급합니다.
  3. 학생이 상품 구매 신청을 했는지 상품 > 구매 관리에서 확인하고, 담당 부서 주문을 처리합니다.
  4. 학생 계정 문제가 생기면 관리 > 사용자 관리에서 반 변경 또는 비밀번호 초기화를 처리합니다.
  5. 학생이나 보호자가 남긴 질문은 Q&A에서 답변하고, 반복 질문은 FAQ로 등록합니다.
부서 담당 교사는 담당 부서 학생의 반 변경과 비밀번호 초기화가 가능합니다. 삭제, 부서 이동 승인, 달란트 반환은 부장 교사 이상 권한이 필요합니다.
권한명, 사용자 유형, 상품 카테고리, 구매 상태 같은 구분값은 공통 코드 기준으로 표시됩니다. 담당 부서 화면과 전체 운영 화면에서 같은 코드값은 같은 이름으로 보입니다. 상품 구매 화면은 카테고리 순번으로 그룹화되고 같은 카테고리 안에서는 상품 정렬 순번 기준으로 표시되며, 상세 모달은 설명 아래에 상세 설명 이미지를 표시할 수 있습니다.

사용자 관리담당 부서 사용자 조회, 가입 신청 처리, 담당 학생 반 변경, 비밀번호 초기화. 교사/학생 로우 클릭으로 상세 정보 모달을 엽니다.상위 권한자나 담당 범위 밖 사용자는 처리 제한이 있습니다.
달란트 관리담당 부서 학생/교사 달란트 지급, 로우 클릭 상세 조회 (누적적립/총사용/총반환/잔여 4칸 요약, 이력 페이징)수동 적립은 관리자만 표시됩니다. 예외 지급은 전도사님 이상, 달란트 반환은 부장 교사 이상입니다.
예외 지급/반환 관리담당 부서의 예외 지급과 반환 이력을 분리 조회합니다.부서 담당 교사는 담당 부서 이력만 볼 수 있습니다.
상품 관리상품 등록/수정, 목록 확인, 상품 정렬 순번 관리, 썸네일/상세 설명 이미지 분리 관리상품 삭제는 전도사님 이상 권한이며, 카테고리 등록·수정·삭제는 구매 담당 교사(70+) 이상 전용입니다. 상품 로우 클릭으로 수정 창을 엽니다.
구매 관리담당 부서 주문 준비/구매 확정/지급 처리구매 담당 교사가 아니면 전체 부서 주문 처리는 제한됩니다.
구매 통계담당 부서 구매 통계 확인전체 부서 필터는 부장 교사 이상 또는 구매 담당 교사에게 넓게 열립니다.
Q&A답변, 댓글, FAQ 등록질문 삭제는 전도사님 이상입니다.

💰 달란트 상세 조회 (v3.48.0)

상세 팝업 요약 4칸

달란트 관리에서 상세를 누르면 팝업 상단에 다음 네 가지가 구분되어 표시됩니다.

  • 누적적립 — 지금까지 받은 달란트 합계
  • 총사용 — 실제 상품 구매 등으로 차감된 달란트 (구매 확정 기준)
  • 총반환 — 잘못 지급되어 되돌린 달란트 (사용과 별도 집계)
  • 잔여 — 현재 사용 가능한 달란트

내역 유형 3종

상세 팝업의 내역 테이블 유형 열에는 적립, 예외, 사용, 반환이 구분됩니다. 예외는 주간 제한을 사유 입력 후 다시 지급한 건이고, 반환은 사용과 별도로 집계됩니다. 총사용에는 실제 상품 구매로 확정된 건만 포함됩니다. 이력은 달란트 관리 목록과 동일한 페이징 버튼과 페이지당 항목 수 선택을 사용합니다.

예외 지급은 전도사님(90+) 이상, 달란트 반환 처리는 부장 교사(80+) 이상 권한입니다. 부서 담당 교사는 내역 확인과 일반 지급을 담당합니다.

🗳️ 추천 상품 비밀 투표

상품 > 상품 추천 투표에서 추천 상품의 입력 정보와 상세 설명 이미지를 확인한 뒤 찬성 또는 반대를 선택합니다. 종료 전 찬성/반대 득표 수는 profiles.is_super_admin=true인 최고관리자만 볼 수 있으며, 종료된 투표는 변경할 수 없습니다. 상세 창의 구매 URL은 상품 보기 버튼으로 엽니다.

추천 등록 시점의 60등급 이상 인원이 기본 정원입니다. 본인이 투표하기 전에는 결과와 찬성/반대 수가 숨겨지고, 완료된 건도 투표중으로 보이며 미완료 필터에 남습니다. 투표 후에만 결과를 확인할 수 있습니다. 채택 시 추천 등록자에게 상품 추천 채택 1달란트가 자동 지급되고, 생성 상품은 순번 999·비활성으로 상품 관리에 등록됩니다. 투표가 끝나면 운영관리 Slack 채널에 상품명·결과·익명 득표 수가 안내되며, 투표자 이름은 전송되지 않습니다. 모바일에서는 상세 모달에서도 찬성 또는 반대를 선택할 수 있습니다. 상품 메뉴 배지는 구매 관리 처리 대기와 본인의 미투표 추천 수를 합산하며, 투표 화면은 구매 관리 바로 아래에 있습니다.
