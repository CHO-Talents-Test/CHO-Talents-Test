# TASK-091 작업 계획 — 운영 조회·상품 검증·가이드 권한 정비

**버전:** v3.89.0  
**작성일:** 2026-07-16

## 목표

운영자가 확인이 필요한 오류와 서비스 수집 실패를 빠르게 확인하고, 사용자 통계·상품 관리·역할별 가이드의 화면 규칙을 현재 권한 체계에 맞춘다.

## 작업 범위

1. 미확인 ERROR/FATAL/CRITICAL 로그 행 클릭 시 상세 모달을 연다.
2. 서비스 통계에 최근 수집 실패의 서비스, 수집 항목, 실패 사유를 표시한다.
3. 사용자 통계에 학생/교사 필터와 날짜·요일·시간·부서·사용자별 막대 그래프를 추가한다.
4. 상품 등록 필수값과 교사/학생 상품 활성 상태 필터를 추가하고, 상점 카드 썸네일을 `contain` 방식으로 표시한다.
5. 모든 가이드의 전환기를 누적 권한 규칙으로 통합하고, 관리자 가이드를 100등급 이상 전용으로 제한한다.
6. 통계 집계와 상세 RPC가 동일하게 사용자 유형을 필터하도록 SQL 보강 파일을 추가한다.

## 영향 범위

- 화면: `admin/logs.html`, `admin/service-stats.html`, `admin/user-stats.html`, `admin/shop.html`, `shop.html`, 7개 역할별 가이드
- 공통: `js/nav.js`, `css/common.css`, `js/version.js`
- DB: `docs/TASK-091_user_stats_filters.sql`
- 문서: README, 사이트 안내서, 아키텍처·설정·초기 설치 문서, 역할별 가이드 및 운영 규칙 페이지

## 적용 순서

1. 정적 파일을 배포한다.
2. 운영 DB에 이미 TASK-081/TASK-084가 적용되어 있으면 `docs/TASK-091_user_stats_filters.sql`을 실행한다.
3. 관리자 계정으로 사용자 통계 필터/상세와 각 권한의 가이드 전환기를 확인한다.
