# TASK-084 변경 보고서: 사용자 통계 상세 조회

## 변경 요약

| 구분 | 변경 전 | 변경 후 |
|---|---|---|
| 통계 표 | 기준·로그인 횟수·로그인 사용자만 표시 | 다섯 통계 표 모두 관리 열과 상세 버튼 제공 |
| 날짜/요일/시간/부서별 | 집계 수치만 확인 | 해당 조건의 사용자 목록, 로그인 횟수, 최근 로그인 시각 확인 |
| 사용자별 | 집계 수치만 확인 | 선택 사용자의 KST 로그인 이력과 당시 부서·권한 확인 |
| 로그인 이력 접근 | 집계 RPC만 제공 | 직접 SELECT는 유지 차단, 관리자 전용 상세 RPC만 추가 |

## 운영 적용

1. 운영 DB의 Supabase SQL Editor에서 `docs/TASK-084_user_login_statistics_detail.sql`을 실행한다.
2. 정적 파일을 배포한다.
3. 관리자(100+) 계정으로 `관리 > 사용자 통계`를 열어 다섯 탭의 상세 버튼과 기간·부서 필터 적용 여부를 확인한다.

## 주의사항

- 상세 데이터는 로그인 시점의 부서·권한 스냅샷이다. 현재 프로필 정보와 다를 수 있으며, 이는 과거 로그인 이력을 정확히 보존하기 위한 동작이다.
- 최고관리자 계정은 기존 정책과 동일하게 이력 및 상세 조회 결과에서 제외된다.
