# TASK-085 상품 추천과 비밀 투표 변경 보고

## 추가 화면

- `product-suggestions.html`: 추천 등록과 내 추천 상태 목록
- `admin/product-suggestion-votes.html`: 60+ 비밀 투표와 관리자 익명 현황

## 데이터 및 보안

- 추천, 등록 시점 투표 정원, 투표를 별도 테이블로 분리했다.
- 브라우저는 전용 RPC만 사용하고 원본 추천/투표 테이블의 직접 조회는 RLS로 차단한다.
- 채택 상품은 추천 카테고리와 추천자 이력을 유지하면서 비활성 상품으로 등록한다.
- 투표 화면, 활동 로그, Slack에서 개별 투표자의 신원과 표 선택을 공개하지 않는다.
- 상품 추천 투표 배지는 등록 시점 투표 정원에 포함된 미투표 추천만 집계하고, 상품 상위 배지는 구매 관리 처리 대기와 합산한다.
- 권한 등급은 `profiles.permission_level` 텍스트로 계산하고, 추천 이미지 Storage 소유자 비교는 UUID/text 스키마 모두에 호환되게 처리한다.
- 내 추천 목록은 요약 그리드와 상세 모달로 구성하며, 모바일 투표 목록은 상세 모달에서 찬성/반대 투표를 제공한다.
- 채택 상품의 비활성 정책은 유지하고, 상품 구매에서는 비노출하며 상품 관리 전체 목록으로 운영 확인 경로를 제공한다.

## 운영 처리

- 기본 과반은 추천 등록 시점의 60+ 정원으로 계산한다.
- 정원 감소로 기존 과반이 불가능할 때 관리자는 현재 유효 정원의 과반 결과로만 종료할 수 있다.
