# TASK-081 작업 계획 — 사용자 로그인 통계

## 목표

- 로그인 성공 건을 사용자·부서·권한 스냅샷과 함께 별도 이력 테이블에 저장한다.
- 관리자(100+)가 KST 기준 날짜별, 요일별, 시간별, 부서별, 사용자별 로그인 통계를 조회하는 `사용자 통계` 페이지를 제공한다.
- 작업 이력과 구매 통계의 행 클릭 상세 모달, 메인 즐겨찾기 20개 제한을 함께 반영한다.

## 범위

1. `user_login_history` 테이블과 기록/집계 RPC를 추가한다.
2. 로그인 성공 뒤 이력 기록 RPC를 호출하고, 실패하더라도 로그인 흐름은 유지한다.
3. `admin/user-stats.html`과 관리 메뉴, 페이지 접근/기능 설정 목록을 추가한다.
4. 관련 사용자 안내, 운영 룰, 설치·구성 문서를 v3.79.0 기준으로 갱신한다.

## 제외 범위

- 기존 로그인 과거 데이터의 소급 생성
- 로그인 원본 행의 UI 직접 열람
- 로그인 성공 알림의 Slack 전송

## 배포 전제

운영 DB에는 `docs/TASK-081_user_login_statistics.sql`을 적용해야 로그인 이력 기록과 통계 RPC가 활성화된다.
