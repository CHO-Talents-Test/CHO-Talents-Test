# TASK-090 테스트 시나리오 — 상품 추천 투표 최고관리자 특례 권한

| 번호 | 역할/입력 | 기대 결과 | 확인 방법 |
|---:|---|---|---|
| 1 | 일반 관리자(`is_super_admin=false`)가 투표 중 목록 조회 | 찬성·반대·총 투표·현재 유효 정원이 비공개 | `get_product_suggestion_vote_items` 반환값과 화면 확인 |
| 2 | 최고관리자(`is_super_admin=true`)가 투표 중 목록 조회 | 익명 진행률, 찬성·반대, 정원·과반 표시 | 화면 및 RPC 반환값 확인 |
| 3 | 일반 관리자가 `close_product_suggestion_vote` 직접 호출 | 최고관리자 권한 오류 | SQL Editor/RPC 응답 확인 |
| 4 | 일반 관리자가 `admin_resolve_product_suggestion` 직접 호출 | 최고관리자 권한 오류 | SQL Editor/RPC 응답 확인 |
| 5 | 최고관리자가 현재 유효 정원 과반 결과가 있는 조기 종료 대상 처리 | 채택 또는 불채택으로 종료되고 Slack 종료 알림 1회 전송 | 상태·작업 이력·Slack 확인 |
| 6 | 최고관리자가 투표 중 직접 채택/불채택 결정 | 결과 처리, 채택 시 기존 1달란트 보상 규칙 유지 | 상품·달란트·Slack 확인 |
| 7 | 종료된 투표를 일반/최고관리자가 다시 투표 | 새 투표와 기존 선택 변경 모두 거부 | RPC 오류 확인 |
