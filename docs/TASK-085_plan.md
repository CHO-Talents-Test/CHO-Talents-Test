# TASK-085 상품 추천과 비밀 투표 계획

## 목표

로그인 사용자가 상품을 추천하고, 부서 담당 교사 이상이 추천 등록 시점의 투표 정원을 기준으로 비밀 투표할 수 있게 한다.

## 범위

- `product-suggestions.html`: 추천 등록과 내 추천 상태 조회
- `admin/product-suggestion-votes.html`: 60+ 비밀 투표, 100+ 익명 진행 현황과 종료 처리
- `product_suggestions`, `product_suggestion_eligible_voters`, `product_suggestion_votes`와 전용 RPC/RLS/Storage 정책
- 내비게이션, 페이지 접근/기능 목록, 코드북, 로그 라벨, 설치 스크립트, 사용자/운영 가이드 갱신

## 결정 사항

- 상품명과 상품 URL 또는 이미지는 필수다.
- 카테고리는 선택하지 않았을 때만 `gift`를 사용한다. 채택 상품에는 선택한 카테고리를 그대로 저장한다.
- 채택 상품은 달란트 0, 순번 0, 학생 대상, 비활성 상태로 만들고 `products.created_by`에 추천자를 기록한다.
- 등록 시점 60+ 계정 목록을 스냅샷해 과반 기준을 고정한다.
- 현재 60+ 상태를 유지한 스냅샷 구성원의 표만 유효 표로 집계한다.
- 현재 유효 정원이 기존 과반보다 적어진 경우에는 자동 완료하지 않는다. 100+ 관리자가 현재 유효 정원의 과반 결과가 있을 때만 종료한다.
- 비밀 투표 보호를 위해 개별 투표자와 선택값을 화면, 활동 로그, Slack에 남기지 않는다.
