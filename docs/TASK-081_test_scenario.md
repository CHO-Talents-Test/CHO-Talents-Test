# TASK-081 테스트 시나리오 — 사용자 로그인 통계

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| TS-01 | 승인된 사용자가 정상 로그인 | `LOGIN_SUCCESS` 뒤 `record_user_login()`이 사용자·부서·권한 스냅샷을 한 건 기록한다. 이력 기록 실패는 로그인 성공을 막지 않는다. |
| TS-02 | 로그인 실패 또는 승인 대기/거부 | `user_login_history`에 행이 추가되지 않는다. |
| TS-03 | 관리자(100+)가 사용자 통계 진입 | 날짜별·요일별·시간별·부서별·사용자별 탭, 기간·부서 필터, KST 집계값이 표시된다. |
| TS-04 | 100 미만 사용자가 사용자 통계 RPC/페이지 접근 | 페이지 권한과 RPC 권한에서 거부된다. |
| TS-05 | 사용자 통계에서 원본 이력 접근 시도 | 테이블 직접 SELECT가 허용되지 않고 집계 RPC 결과만 반환된다. |
| TS-06 | 작업 이력 그리드 행 클릭 | 기존 상세 모달이 열린다. 상세 버튼 클릭은 행 클릭과 중복 실행되지 않는다. |
| TS-07 | 구매 통계 전체·부서별·사용자별 행 클릭 | 각각 상품·부서·사용자 상세 모달이 열린다. |
| TS-08 | 메인 즐겨찾기 설정 | PC·모바일 모두 최대 20개까지 선택할 수 있다. |
| TS-09 | 빈 새 DB 설치 | PowerShell/Bash 설치 스크립트 합본에 TASK-081 SQL이 포함된다. |
