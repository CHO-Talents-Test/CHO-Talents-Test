6. 24시간 세션 관리 및 리디렉트 로그

js/auth.js의 initPage()가 성공하면 startSessionTimer()가 자동 시작됩니다. 마지막 활동(클릭·키입력·스크롤·터치 등)으로부터 24시간 유휴 시 세션이 만료되고 로그인 페이지로 이동합니다. 활동 시간은 localStorage(cho_last_activity)로 멀티탭 간 공유되며, 탭 전환 시에도 만료 여부를 재검증합니다. v3.53.0부터 세션 없음/만료, 최초 로그인 이동, 권한 등급 부족, 허용 권한 불일치, role_page_access 차단은 AUTH_REDIRECT 로그에 요청 페이지, page_id, 필요/실제 권한, 이동 대상을 남깁니다. v3.66.1부터 js/version.js가 최신 버전과 세션 버전을 비교해 구버전 자산은 재검증하고, 구버전 세션은 APP_VERSION_STALE_SESSION 로그 후 재로그인을 안내합니다.
