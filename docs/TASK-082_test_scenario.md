# TASK-082 테스트 시나리오 — 최고관리자 로그인 이력 제외

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| TS-01 | 최고관리자 로그인 성공 | `record_user_login()`이 정상 종료하되 `user_login_history` 행을 추가하지 않는다. |
