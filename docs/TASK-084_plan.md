# TASK-084 작업 계획: 사용자 통계 상세 조회

## 목표

1. 사용자 통계의 날짜·요일·시간·부서·사용자별 표에 `관리` 열과 `상세` 버튼을 추가한다.
2. 날짜·요일·시간·부서별 상세에는 해당 조건의 사용자 목록을 표시한다.
3. 사용자별 상세에는 선택한 사용자의 로그인 이력을 표시한다.
4. 원본 로그인 이력 테이블 직접 조회 권한은 유지하지 않고 관리자(100+) 전용 RPC로만 상세 데이터를 반환한다.

## 상세 표시 기준

- 사용자 목록: 사용자명·계정, 당시 부서, 당시 권한, 로그인 횟수, 최근 로그인 시각(KST)
- 사용자 로그인 이력: 로그인 시각(KST), 당시 부서, 당시 권한
- 기간과 부서 필터는 집계와 상세 조회에 동일하게 적용한다.

## 영향 범위

- `admin/user-stats.html`: 관리 열, 상세 모달, 상세 RPC 호출 및 표 렌더링
- `docs/TASK-084_user_login_statistics_detail.sql`: 상세 조회 RPC와 실행 권한
- 설치 스크립트·설치 문서·사용자/관리자 가이드·버전 이력: 새 운영 DB와 기존 운영 DB 적용 기준 동기화
