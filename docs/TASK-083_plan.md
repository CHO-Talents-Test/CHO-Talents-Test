# TASK-083 작업 계획: 달란트 적립 카드 동적 생성과 이모지 관리

## 배경

`earn-talents.html`은 미리 작성된 카드의 항목명과 DB 항목명을 비교해 금액·규칙·설명만 변경했다. 따라서 관리 화면에서 새로 추가한 활성 항목은 대응하는 고정 카드가 없어 적립 안내에 표시되지 않았다.

## 목표

1. 학생/교사별 활성 `talent_items` 전체를 정렬 순서대로 카드로 표시한다.
2. 달란트 항목에 카드 이모지를 저장하고, 관리 화면과 적립 안내에 동일하게 표시한다.
3. 기존 운영 DB와 새 DB 설치 모두에서 `emoji` 컬럼을 지원한다.

## 영향 범위

- `earn-talents.html`: 고정 카드와 이름 별칭 매칭 제거, DB 행 기반 카드 렌더링 적용
- `admin/talent-items.html`: 이모지 입력·수정·목록 표시 및 작업 로그 보강
- `docs/TASK-083_talent_item_emoji.sql`: 운영 DB용 컬럼/기본값/기존 이모지 보정
- `docs/INITIAL_DATABASE_SETUP.sql`: 새 DB 기본 스키마 반영
- README 및 설치·사용자·구성·아키텍처 문서, 관련 가이드, 버전 이력

## 완료 기준

- `SGS 포토존 미션 시상`처럼 새로 등록한 활성 학생 항목이 별도 HTML 수정 없이 학생 탭에 표시된다.
- 항목 추가/수정 모달에서 입력한 이모지가 목록과 적립 카드에 표시된다.
- 비활성 항목은 적립 카드에 표시되지 않는다.
