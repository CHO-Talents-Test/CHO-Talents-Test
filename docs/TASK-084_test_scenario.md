# TASK-084 테스트 시나리오: 사용자 통계 상세 조회

| ID | 조건 | 기대 결과 |
|---|---|---|
| TC-084-01 | 날짜별·요일별·시간별·부서별·사용자별 탭 표시 | 각 표의 마지막에 `관리` 열과 `상세` 버튼이 표시된다. |
| TC-084-02 | 날짜별 행의 상세 버튼 클릭 | 선택 날짜와 현재 기간·부서 필터에 해당하는 사용자 목록, 로그인 횟수, 최근 로그인 시각(KST)이 표시된다. |
| TC-084-03 | 요일별 또는 시간별 행의 상세 버튼 클릭 | 선택 요일 또는 시간대에 로그인한 사용자 목록이 표시된다. |
| TC-084-04 | 부서별 행의 상세 버튼 클릭 | 선택 부서의 사용자 목록이 표시되며 미배정 그룹도 조회된다. |
| TC-084-05 | 사용자별 행의 상세 버튼 클릭 | 선택 사용자의 로그인 시각(KST), 당시 부서, 당시 권한이 최신순으로 표시된다. |
| TC-084-06 | 기간·부서 필터를 변경한 뒤 상세 조회 | 집계와 동일한 필터 조건의 상세 데이터만 표시된다. |
| TC-084-07 | 관리자(100+) 미만 계정이 상세 RPC 호출 | `insufficient permission`으로 거부된다. |
| TC-084-08 | 로그인 이력 테이블 직접 SELECT | 기존 RLS/권한 회수 정책에 따라 계속 허용되지 않는다. |
