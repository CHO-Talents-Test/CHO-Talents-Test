# TASK-086 관리자 상품 추천 예외 결정 변경 보고

## 변경 내용

- 관리자(100+)가 투표중 추천 상품 상세 모달에서 투표 완료 여부와 관계없이 채택 또는 불채택을 결정할 수 있다.
- 전용 `admin_resolve_product_suggestion` RPC가 서버에서 관리자 권한과 투표중 상태를 확인한 뒤 기존 상품 생성 처리기를 재사용한다.
- 채택 상품은 기존 규칙대로 달란트 0, 순번 0, 학생 대상, 비활성으로 생성된다.
- 기존 `close_product_suggestion_vote`의 현재 유효 정원 과반 종료 조건은 그대로 유지한다.
- 결정 로그에는 결과와 `관리자 예외 결정` 처리유형만 기록하며, 추천자·투표자·개별 찬반은 노출하거나 기록하지 않는다.

## 적용 순서

1. 기존 상품 추천 설치가 끝난 DB에서 `docs/TASK-086_product_suggestion_admin_decision.sql`을 실행한다.
2. 정적 사이트 파일을 배포한다.
3. 관리자와 부서 담당 교사 계정으로 권한별 표시와 처리 결과를 확인한다.
