# TASK-085 상품 추천과 비밀 투표 테스트 시나리오

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| TS-01 | 로그인 사용자가 상품명만 입력 | URL 또는 이미지 필수 안내 |
| TS-02 | URL과 카테고리 없이 추천 등록 | 추천 저장, 카테고리는 `gift`, 내 목록에 투표중 표시 |
| TS-03 | 이미지 파일만 첨부해 추천 등록 | `Talents_Items/product-suggestions/`에 업로드 후 추천 저장 |
| TS-04 | 관리자가 카테고리를 선택해 추천 등록 | 선택 카테고리, 0 달란트/순번, 학생 대상, 비활성 상품 즉시 생성 |
| TS-05 | 60+ 사용자가 투표 전 목록 조회 | 결과/찬반 수 비공개, 상태는 투표중 |
| TS-06 | 60+ 사용자가 찬성 또는 반대 투표 | 본인 투표 후 집계와 실제 상태 조회 가능, 추천자/투표자 미노출 |
| TS-07 | 등록 시점 과반의 찬성 또는 반대 확보 | 채택 시 비활성 상품 생성, 반대 과반 시 불채택 |
| TS-08 | 미투표자가 완료된 추천을 미완료 필터로 조회 | 미완료에 표시되고 투표중으로 보임 |
| TS-09 | 관리자가 목록 조회 | 투표자 이름 없이 진행률, 찬성, 반대, 등록/현재 정원 표시 |
| TS-10 | 현재 유효 정원이 등록 시점 과반보다 감소 | 일반 투표는 미완료, 관리자에게만 종료 처리 영역 표시 |
| TS-11 | 현재 유효 정원 과반 결과가 있는 종료 대상 | 관리자 종료 처리 후 채택 또는 불채택 완료 |
| TS-12 | 현재 유효 정원 과반 결과가 없는 종료 대상 | 종료 버튼 비활성 또는 RPC 거부 |
| TS-13 | 등록 시점 투표 정원에 포함된 사용자의 미투표 추천 존재 | 상품 추천 투표 배지에 미투표 수 표시, 상품 상위 배지는 구매 관리 배지와 합산 |
| TS-14 | 내 추천 목록의 행 또는 상세 버튼 선택 | 채택여부, 상품명, 추천일, 상세만 표시되고 전체 입력 정보 모달 표시 |
| TS-15 | 채택된 비활성 상품을 60+ 계정으로 상품 구매/상품 관리에서 조회 | 상품 구매에는 표시되지 않고, 상품 관리에는 상태와 함께 표시 |
| TS-16 | 모바일 상품 추천 투표 목록과 상세 모달 | 다섯 열만 표시, URL·이미지·설명과 찬성/반대 투표 제어는 모달에서 제공 |
