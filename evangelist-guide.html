🎫 QR 운영 순서

  1. 달란트 > 달란트 QR 관리에서 지급 대상이 학생인지 교사인지 선택합니다.
  2. 달란트 항목을 선택하거나 직접 입력으로 설명과 금액을 입력합니다.
  3. 무제한/선착순, 지정일/기간/무기한, 반복 수령 여부를 설정합니다.
  4. 위치 제한이 필요하면 카카오맵 검색으로 장소와 반경을 지정합니다. 수령자의 기기나 브라우저 위치 권한이 차단되어 있으면 달란트 수령 화면에서 알림창과 안내 메시지가 표시됩니다.
  5. 생성 후 QR 이미지를 인쇄하거나 화면으로 공유합니다.
  6. 운영이 끝난 QR은 비활성화하고 수령자 목록을 점검합니다. 수령자 팝업은 사용자별로 묶어 표시되며 사용자 유형(전체/교사/학생), 부서, 이름/아이디 검색 필터와 페이지당 항목 수 콤보 박스(3~30개, 계정별 DB 저장)를 지원합니다. 사용자 로우를 선택하면 해당 사용자에게 지급된 항목 상세와 반환 상태가 아래에 표시됩니다.
QR 수정은 기존 코드를 바꾸는 것이 아니라 새 QR 코드를 만드는 방식입니다. 이미 배포한 QR을 바꾸면 새 코드로 다시 안내해야 합니다.

💰 달란트 상세 · 예외 지급 · 반환 구분 (v3.60.0)

달란트 관리 상세 팝업 상단에는 누적적립, 총사용, 총반환, 잔여 4칸이 표시됩니다. 내역 유형은 적립, 예외, 사용, 반환으로 구분되며, 예외 지급과 반환은 각각 별도 배지로 표시됩니다. 상세 이력은 공통 페이징과 페이지당 항목 수 설정을 사용합니다. 총사용에는 실제 상품 구매 확정 건만 포함됩니다.

이미 이번 주 지급된 항목을 다시 지급해야 하면 이번 주 제한 예외 지급을 선택하고 사유를 입력한 뒤 항목을 다시 선택합니다. 이 기능은 전도사님(90+) 이상만 사용할 수 있습니다.

달란트 > 예외 지급/반환 관리에서는 예외 지급과 반환 이력을 분리해 처리자, 대상자, 사유, 처리 시각을 확인합니다.

✅ 운영 점검 포인트

  • 달란트 항목의 지급 규칙과 설명이 학생 가이드/적립 화면에 보이는 문구와 맞는지 확인합니다.
  • 상품 삭제 전 진행 중인 주문이 없는지 구매 관리에서 먼저 확인합니다.
  • 상품 카테고리, QR 대상/반복 유형, 구매 상태, 로그/작업 유형 명칭은 공통 코드 기준으로 표시됩니다. 로그 상세는 영어 key로 저장하고 화면과 Slack 알림에서는 한글로 변환합니다. 상품 카테고리는 상품 카테고리 관리 페이지에서 추가·수정·삭제하며, 상품 이미지는 썸네일과 상세 설명 이미지로 나누어 관리합니다. 명칭을 바꿀 때는 개별 화면 문구보다 코드 마스터 기준을 먼저 확인합니다.
  • 공지 운영 후 열람 현황에서 등록일시/등록자와 사용자 유형을 확인하고, 전체/확인자/미확인자 콤보박스로 대상을 좁혀 아직 확인하지 않은 사용자에게 필요한 안내를 별도로 전달합니다.
  • 부서 비활성화 전 소속 사용자와 가입 신청, 부서 이동 요청을 확인합니다.
  • Q&A 삭제는 민감한 내용, 중복, 잘못된 질문에 한정하고 FAQ 전환 가능성을 먼저 봅니다.
  • Slack 알림 룰 페이지에서 어떤 이벤트가 어느 채널로 가는지 확인해 운영자에게 안내합니다.
  • 서비스 통계 페이지에서 GitHub/Supabase/Kakao/Slack 무료 할당량 사용률을 확인합니다. 자동 수집은 매시간 정각에 실행되고, 70%·85%·95% 알림은 운영 Slack 채널로 전송됩니다. 180일 초과 수동 삭제는 관리자(100+) 전용입니다.

🗳️ 추천 상품 비밀 투표

상품 > 상품 추천 투표에서 추천 상품의 상품명, 이미지·상세 이미지, 설명, 금액, 카테고리를 확인하고 비밀 투표합니다. 일반 권한자는 종료 전 득표 수를 볼 수 없고, 종료된 투표는 변경할 수 없습니다. 구매 URL은 상품 보기 버튼으로 엽니다.

전도사님 권한은 찬성/반대 투표와 상세 확인을 제공하지만, 채택 시 추천 등록자에게 상품 추천 채택 1달란트가 자동 지급됩니다. 등록과 종료 결과는 운영관리 Slack 채널에 상품명·결과·익명 득표 수만 안내됩니다. 정원 감소 상황의 투표 종료, 전체 진행률 집계, 투표중 채택/불채택 예외 결정은 profiles.is_super_admin=true인 최고관리자 전용입니다.
